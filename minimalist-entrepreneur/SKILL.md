# Minimalist Entrepreneur — 极简创业 AI 商业顾问

> 基于 Sahil Lavingia 畅销书《The Minimalist Entrepreneur》（《小而美》）提炼的 10 个 Claude Code Skill。不是教程，是对话式商业顾问——带着你的真实想法来，它会一步步追问你。

## 核心理念

```
公司不一定要做大。活下去靠的是盈利，不是融资。
活下来之后，增长是自然发生的。
                                        — Sahil Lavingia, Gumroad 创始人
```

Sahil Lavingia 是 Pinterest 联合创始人（二号员工），2012 年创立 Gumroad。在裁掉四分之三员工、最终只剩自己一人之后，他想通了一件事：**极简创业不是怎么做大，是怎么活下来。**

他把这套方法论写成了《The Minimalist Entrepreneur》，又进一步提炼成了 10 个可交互的 Claude Code Skill。

## 10 步创业全链路

```
找社群       验证想法        MVP         流程化      首批100客户
  │             │             │             │             │
  ▼             ▼             ▼             ▼             ▼
/find-    /validate-      /mvp       /processize   /first-
community   idea                                  customers
  │             │             │             │             │
  └─────────────┴──────┬──────┴─────────────┴─────────────┘
                       │
          定价          营销        稳健增长     公司价值观     极简复盘
           │             │             │             │             │
           ▼             ▼             ▼             ▼             ▼
       /pricing    /marketing-     /grow-       /company-   /minimalist-
                     plan       sustainably      values       review
```

每一步都是下一步的前提。没有社群就没有人买你的东西，不验证想法就会做出来没人要，不先手动跑通就写代码，大概率写出来的东西和真实需求对不上。

## 10 个 Skill 详解

### 1. `/find-community` — 找社群

**一句话核心**：你不需要找社群，你已经属于好几个了。关键是里面的人在反复抱怨什么。

**它会问你**：
- 你已经在哪些社群里？（职业、兴趣、地域、线上/线下）
- 这些社群里，人们反复抱怨什么问题？
- 有没有人已经在尝试解决？为什么没解决？

**输出**：一个具体的社群 + 一个反复出现的问题 = 你的创业起点。

---

### 2. `/validate-idea` — 验证想法

**一句话核心**：别问"酷不酷"，问"有人付钱吗"。

**它会问你**：
- 你能说出 10 个具体的人有这个问题吗？
- 他们中有 3 个说愿意付钱吗？
- 他们现在怎么解决的？有多痛？
- 你自己愿意为这个解决方案付钱吗？（如果你自己都不愿意，目标用户大概率也不会）

**输出**：想法通过/不通过/需要更多验证 + 下一步行动。

---

### 3. `/mvp` — 最小可行产品

**一句话核心**：只做一件事，能在周末交付的才做。

**它会问你**：
- 这个产品只做一件事，那件事是什么？
- 能不能在一个周末（48 小时）内交付？
- 砍掉所有"有了更好"的功能，剩下的那一个是什么？

**输出**：MVP 范围定义 + 周末交付计划。

---

### 4. `/processize` — 流程化

**一句话核心**：先手动跑 10 次，把步骤写在纸上，再写代码。

**它会问你**：
- 你能不能手动完成这个服务？（不写任何代码）
- 手动跑 10 次之后，哪些步骤是重复的？
- 哪一步最浪费时间？那一小步才值得自动化。

**输出**：手动流程文档 → 自动化优先级列表。

---

### 5. `/first-customers` — 首批 100 客户

**一句话核心**：100 个客户之前别搞发布会，从亲友一圈圈往外卖。

**它会问你**：
- 你认识的人里，谁最可能有这个问题？
- 你上一次直接跟潜在客户聊是什么时候？
- 第一批 10 个人是谁？怎么联系他们？

**输出**：第一批客户名单 + 外扩策略。

---

### 6. `/pricing` — 定价

**一句话核心**：从第一天就收费。免费和 1 块钱之间是质变不是量变。

**它会问你**：
- 你提供的这个东西，帮用户省了多少钱/时间？
- 竞品收多少钱？用户现在为这个问题付多少钱？
- 如果你必须从第一天就收费，你收多少？

**输出**：定价方案 + 收费时机策略。

---

### 7. `/marketing-plan` — 营销计划

**一句话核心**：先花时间再花钱。博客免费、社交免费，跑通了再投广告。

**它会问你**：
- 你的目标客户在哪里获取信息？
- 你能不能先写 10 篇博客/发 10 条推文/做 10 个视频？
- 哪一类内容能同时做到"教育用户"和"展示产品"？

**输出**：内容营销日历 + 渠道优先级排序。

---

### 8. `/grow-sustainably` — 稳健增长

**一句话核心**：盈利给你无限跑道。别人可能超过你，但 10 年后你还在。

**它会问你**：
- 你现在盈利吗？如果不，离盈利还差多少？
- 增长是不是在烧钱换来的？烧完还能活吗？
- 如果接下来 12 个月零增长，公司还能活吗？

**输出**：可持续增长诊断 + 风险暴露清单。

---

### 9. `/company-values` — 公司价值观

**一句话核心**：价值观用故事写，不是口号。Nordstrom 接受轮胎退货才是价值观。

**它会问你**：
- 有没有一个故事能说明你公司的价值观？（不是"我们相信XX"）
- 如果价值观和赚钱冲突，你选哪个？有没有真实发生过？
- 你招人的时候，会因为价值观不合拒绝一个能力强的人吗？

**输出**：价值观故事草稿 + 行为面试题。

---

### 10. `/minimalist-review` — 极简决策复盘

**一句话核心**：八个问题筛完，答案通常就清楚了。这是 10 个 Skill 里最通用的一个。

**八个过滤问题**：
1. 这个决策能在一个周末内执行吗？
2. 不花额外的钱能做吗？
3. 有人为此付过钱吗？
4. 如果不做，最坏的结果是什么？
5. 这个决策是可逆的吗？
6. 你的客户真的在要求这个吗？还是你自己觉得应该做？
7. 有更简单的方法达到同样的效果吗？
8. 如果你必须在 24 小时内做出决定，你会怎么做？

**输出**：8 维评分 + 最终决策建议。

## 两个 Skill 接力的力量

这 10 个 Skill 不是各管一段，而是**前一个的结论是后一个的前提**。实操中最常见的组合：

```
/validate-idea  →  /minimalist-review
（验证想法本身）     （用8条原则最终过筛）
```

只用 `/validate-idea`，你知道"想法还没验证，需要更多信息"。加了 `/minimalist-review` 之后，结论更清晰：不是"验证不够"的问题，是这个想法从一开始就不该以"做产品"的方式推进。

**这就是链路的意义：不是每个 Skill 各管一段，而是接力用，你看到的就不是某个点的问题，而是整条路径的问题。**

## 安装方式

### 方式一：Plugin 安装（推荐，使用原版）

```bash
/plugin marketplace add slavingia/skills
/plugin install minimalist-entrepreneur
```

重启 Claude Code 对话即可使用。

### 方式二：安装本仓库文档包装器

```bash
cp -r minimalist-entrepreneur ~/.claude/skills/minimalist-entrepreneur
```

安装后，当你说"帮我验证一个创业想法"或"我该不该做这个功能"时，Claude Code 会自动触发本 Skill，引导你使用对应的子技能。

## 使用建议

1. **一定要说实话** — 对 AI 商业顾问撒谎没意义。如果你自己都不愿意付费，就说"我不愿意"，它会立刻指出这是红旗。硬撑说"朋友们都在求我做"，判定结果也是假的。
2. **别当教程看，当对话用** — 最浪费的用法是打开 → 看完 → 觉得"嗯有道理" → 关掉。正确用法是带着真实想法去对话，让它一步步追问你。
3. **用 `/minimalist-review` 做日常决策过滤器** — 这是 10 个 Skill 里最通用的一个。任何商业决策都可以用它过一遍：该不该招人？该不该租办公室？该不该做这个功能？
4. **先读懂逻辑，再用 Skill** — 建议先把《小而美》读一遍，理解了为什么先找社群再验证想法、为什么强调手动落地再产品化，才能真正吃透这些工具。

## 不止创业

哪怕你不创业，只是想做一个副业、开一个社群、甚至想搞清楚"我这个想法到底靠不靠谱"，里面至少有 5 个 Skill 对你有用：

| Skill | 用途 |
|-------|------|
| `/find-community` | 帮你找到你真正属于的圈子 |
| `/validate-idea` | 帮你判断"做这个值不值" |
| `/processize` | 帮你把想法变成"今天就能动手做的事" |
| `/pricing` | 帮你搞清楚"我该收多少钱" |
| `/minimalist-review` | 帮你过筛任何"我到底该不该做这个"的纠结 |

**一个人不一定非得做公司。但一个人做事的逻辑是一样的：先想清楚给谁做，再验证值不值得做，然后手动跑通，最后才是放大。**
