## 改编内容

本目录的 `SKILL.md` 包含：
- 10 个极简创业子技能的完整索引和链路图
- 中英双语触发关键词
- 每个子技能的一句话核心 + 它会问你的问题 + 输出格式
- 实操案例：两个 Skill 接力验证创业想法
- 安装方式汇总（Plugin 原版 + 本地文档包装器）
- 使用建议和常见误区

### 改编变更
- 从 Claude Code Plugin 格式适配为 Dog-Skills SKILL.md 格式
- 添加 YAML 前置元数据（name, description, allowed-tools, metadata）
- 添加中英文双语触发关键词（含中文创业场景高频词）
- 将 Plugin 内嵌的 10 个命令拆解为结构化文档（链路图 + 详解表）
- 新增"两个 Skill 接力"的实操案例说明
- 新增"不止创业"章节（非创业者的 5 个可用 Skill）
- 添加上游项目信息和作者背景

### 未包含的内容
- 原始 Plugin 的完整 prompt 指令（版权属于 Sahil Lavingia）
- 本 SKILL.md 是文档包装器和触发入口，实际执行逻辑在原始 Plugin 中
