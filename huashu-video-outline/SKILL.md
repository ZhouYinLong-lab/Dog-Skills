# 视频大纲生成

> 基于 [huashu-skills](https://github.com/alchaincyf/huashu-skills) (1.2k+ stars)。

## 核心功能

- 快速生成2-3个视频脚本大纲方案
- 每个方案含标题、封面建议、结构设计、时长预估
- 多方案对比，选最优方向
- 适合在选题阶段快速评估

## 使用示例
```
帮我生成几个关于AI工具评测的视频大纲方案
```
