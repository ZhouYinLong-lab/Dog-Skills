# 设计哲学顾问

> 基于 [huashu-skills](https://github.com/alchaincyf/huashu-skills) (1.2k+ stars)。
> 像顶级设计公司那样理解需求。

## 核心能力

- **20种设计哲学**，5大流派
- 每次推荐3个不同流派的方向 + 并行生成3个视觉Demo
- 设计完成后自动启动专家评审（5维度0-10分打分）
- 生成可直接使用的AI提示词DNA

## 使用示例
```
帮我设计一个AI产品落地页的视觉风格
```
