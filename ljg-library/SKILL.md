# ljg-library：取景框借书卡

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 核心概念

一本书铸成一张2050图书馆借书卡。提炼作者独创的"取景框"——从某个角度看某个问题，看到了一幅别人没看到的画面。吉田诚治式绘本感插画+费曼式讲解。

## 使用示例
```
给《黑客与画家》铸一张取景框借书卡
```
