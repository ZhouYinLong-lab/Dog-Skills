# ljg-roundtable：圆桌讨论

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 核心玩法

- 主持人请来3-5位真实人物
- 定义开场，逐轮交锋
- 每轮收一张ASCII结构图
- 用户用指令控节奏：可/止/深入此节/引入新人物
- 散场后全文存入笔记

## 使用示例
```
开个圆桌讨论：AI是否拥有真正的创造力？
```
