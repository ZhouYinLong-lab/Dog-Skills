# 领域论文地图

## 选择原则

按用户的学习目标选择资料，不要按引用数机械排序。优先覆盖：

- 起点或源头工作；
- 关键范式变化；
- 代表性方法；
- 重要争议或失败路线；
- 当前主流与最新前沿。

一个领域可以有多个起点。若找不到可靠的“开山论文”，使用教材或综述中的历史节点作为入口，并明确这是代理判断。

## 论文卡片

```text
论文：作者，年份，链接
角色：起点 / 转折 / 代表方法 / 争议 / 前沿
它解决的问题：
它继承了什么：
它改变了什么：
它留下的局限：
后续回应：
推荐阅读位置：
来源与可信度：
```

## 地图输出

先给一段总览，再给 3—7 篇核心论文，最后给外围资料。每篇论文都必须回答“为什么读它”，而不是只给标题。

建议使用：

```text
旧问题 → 新想法 → 新方法 → 新局限 → 下一代方法
```

外围论文不是额外任务清单，而是挂在核心节点上的解释、对比、应用或延伸材料。根据用户时间预算标注必读、选读和备用。
