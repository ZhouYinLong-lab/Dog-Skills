# 直觉优先阅读

## 第一遍目标

第一遍阅读的完成标准是：用户能够解释作者为什么开始做这项工作，以及这项工作的核心想法如何回应旧问题。不要默认第一遍完成所有数学推导。

## 直觉卡片

```text
论文：
一句话直觉：
作者观察到的问题：
旧方法的瓶颈：
新的关键假设：
方法如何实现这个直觉：
最能证明它有效的证据：
最重要的限制：
后续论文如何修正：
暂时可以延后的细节：
我还不能解释的地方：
```

## 技术阻塞处理

当用户被公式或术语卡住时，按以下顺序处理：

1. 先用直觉语言说明它在整篇论文中的作用；
2. 判断它是否阻断对主线的理解；
3. 若不阻断，记录到细节队列；
4. 若阻断，只补足理解当前论点所需的最小前置知识；
5. 回到论文主线，避免在局部问题上无限展开。
