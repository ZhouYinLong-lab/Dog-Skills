# 默认交付模板

## 学习契约

```markdown
# 学习契约
- 主题：
- 具体目标：
- 重点范围：
- 暂不展开：
- 可选：已有基础、时间预算、目标深度、最终产物（仅在用户主动提供或需要时补充）
```

## 最终报告

```markdown
# [主题] 快速学习路线

## 1. 先说结论
用一段话说明这个领域的主线。

## 2. 学习契约
复述已经确认的范围和目标。

## 3. 论文地图
按阅读顺序列核心论文与外围资料，并说明每篇为什么读。

## 4. 核心直觉
逐篇输出论文直觉卡片。

## 5. 知识结构
说明问题、方法、局限和后续回应之间的关系。

## 6. 细节队列
列出下一轮值得补的技术细节和前置知识。

## 7. 自测问题
用 3—5 个问题检验用户能否复述主线。
```
