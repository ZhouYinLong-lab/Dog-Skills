# 知识结构与细节循环

## 三层结构

```text
层 1：领域主线——研究从什么问题走到什么问题
层 2：论文直觉——每篇核心工作为什么成立
层 3：技术细节——公式、证明、实现和实验如何支撑直觉
```

先建立层 1，再提炼层 2，最后按需要补层 3。每次补完细节都要回到层 1 和层 2，检查原有理解是否需要修正。

## 关系记录

每个核心节点至少记录：

```text
前置问题：
核心直觉：
关键机制：
解决了什么：
仍然缺什么：
被谁继承、改进或反驳：
```

## 每轮复盘

```text
已经理解：
仍然模糊：
本轮补充的细节：
对整体地图的修正：
下一步验证：
```

用这些记录控制范围。当用户能够解释核心节点之间的因果关系、定位新论文的位置，并提出合理的后续问题时，可以结束当前阶段。
