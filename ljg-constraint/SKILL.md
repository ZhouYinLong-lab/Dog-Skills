# ljg-constraint：约束引擎

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 三层约束

- **硬约束（世界层）**：物理规律、数学极限——不可逾越
- **软约束（规则层）**：制度、标准、协议——可改变但需代价
- **自设约束（认知层）**：习惯、假设、隐喻——往往被误当事实

## 使用示例
```
找一下AI编程工具这个领域的本质约束
```
