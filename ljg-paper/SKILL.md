# ljg-paper：读完只带走一件事

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 核心目标

让一个不懂该领域、但愿意思考的人，在半分钟内知道：
- 论文被什么问题逼出来
- 作者多看见了什么
- 这会改变读者的哪个判断或动作

## 使用示例
```
帮我读一下这篇Attention Is All You Need论文
```
