# ljg-book：读懂一本书的 x → f → f(x)

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。
> 把一本书还原成一条完整的逻辑链。

## 核心框架

- **x**：作者到底在处理什么问题
- **f**：作者给出的核心回答——概念、区分、框架、方法、模型或叙事视角
- **f(x)**：把这个回答放回问题后，我们应当怎样重新理解、判断或行动

## 使用示例
```
帮我拆一下《思考，快与慢》这本书
```
