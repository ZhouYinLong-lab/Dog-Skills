# 视频脚本口语化审校

> 基于 [huashu-skills](https://github.com/alchaincyf/huashu-skills) (1.2k+ stars)。

## 核心功能

- 删除书面腔，加入自然口语词
- 短句化处理，标注停顿和重音
- 适合录制前的最后一轮打磨

## 使用示例
```
这个脚本太书面了，帮我改成适合口语表达
```
