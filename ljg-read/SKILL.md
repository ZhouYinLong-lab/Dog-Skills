# ljg-read: 伴读

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 核心理念

- 翻译是再生产，不是搬运——信是不歪，达是懂了，雅是住下来了
- 伴读是脚手架，最终要拆——读者被激活才算有效
- 扫清语言障碍只是起手式，真正的活儿是让你撞见自己从没想过的问题

陪我读一下这篇英文论文
