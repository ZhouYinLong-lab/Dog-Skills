# ljg-think: 追本之箭

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。
> 一支离弦之箭。射出后只知前进，不知后退。

## 核心理念

每个观点都是一条通向本质的隧道。输入一个观点，一路向下，钻到底。不是广度调查——是深度钻探，像箭一样穿透表象层层直抵不可再分的本质。

## 使用示例
```
追本：为什么AI编程工具的发展这么快
```
