# ljg-map：生态地形图卡

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。
> 地基：参考系理论（《千脑智能》）。

## 核心框架

- **生态地形**：价值之河在地貌间流动
- **瓶颈**：流量/产能在此收窄的隘口
- **价值捕获点**：利润在此沉淀的宝藏堆
- 三个关键指标 + 三个前沿大问题

## 使用示例
```
画一下AI编程工具这个行业的生态地形图
```
