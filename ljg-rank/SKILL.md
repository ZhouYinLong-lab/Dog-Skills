# ljg-rank：降秩引擎

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 秩是什么

秩不是"关键要素"，不是"核心原则"，不是"总结要点"。秩是这个领域里真正独立的生成器——拿这几根，能把全部现象一个个倒回来。能倒回来只是底线，还要过 Deutsch 的两关：解释力（reach）和难以变更（hard to vary）。

## 使用示例
```
给AI Agent这个领域降秩，找出它的根骨架
```
