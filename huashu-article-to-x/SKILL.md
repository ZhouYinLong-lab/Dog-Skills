# 长文转社交媒体

> 基于 [huashu-skills](https://github.com/alchaincyf/huashu-skills) (1.2k+ stars)。

## 核心功能

- 3000-5000字长文 → 200-500字社交内容
- 3种开头风格：金句型 / 数据型 / 价值主张型
- 保持口语化和真实感，不是简单删减
- 自动提取核心观点和最佳案例

## 使用示例
```
把这篇文章转成小红书帖子
```

## 安装
```bash
git clone https://github.com/alchaincyf/huashu-skills.git ~/.claude/skills/huashu-skills/
```
