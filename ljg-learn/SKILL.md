# ljg-learn: 概念解剖

> 基于 [ljg-skills](https://github.com/lijigang/ljg-skills) (6.5k+ stars)。

## 八维解剖

拿到一个概念，从八个方向切开它：历史、辩证、现象学、语言学、形式化、存在主义、美学、元哲学。最后把所有切面压成一句顿悟。

## 使用示例
```
解剖一下"熵"这个概念
```
